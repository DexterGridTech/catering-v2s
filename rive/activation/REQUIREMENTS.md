# TER 激活页 Rive 动画 · 原始需求与设计记录

## 1. Dexter 原始需求（2026-10-06，原话）

> 我现在希望在rive目录下，建一个activation的rive工程，制作一个rive动画，用于TER激活页面的动画，当前TER激活需要8位激活码，我希望做一个长为600高为150的rive矢量动画，左边是一个终端的图，类似一个显示器，右边是一个服务器的图，类似一个云服务，中间是一个自左向右的箭头（暂定黑色，要作为参数可以设置），箭头的线是一个虚线，虚线分为了8段，箭头不动，但虚线自左向右循环移动（暂定每秒移动100，要作为参数可以设置），类似跑马灯一样循环播放。动画有9个状态，RN每输入一个激活码（0-8），对应一个状态，输入一个激活码，虚线的一段就会变粗（暂定是原来的2.5倍，要作为参数可以设置）但不影响其循环移动，直到8个激活码都输入完，所有虚线段都变粗。背景要是透明的。左右两个图要设计的科技感强一点。请先记录我的原始需求，然后开始设计，本次不动RN，不改代码，只通过rive 的MCP或CLI设计动画。

## 3. 设计决定与待确认（由 Claude 在设计中补全，Dexter 可改）

### 已实现功能

1. **画布与布局**：600×150，透明背景 ✓
2. **左侧终端图标**：蓝色显示器外框 + 底座 + 发光屏幕 ✓
3. **右侧云服务图标**：绿色云形状（3个椭圆 + 底部矩形） ✓
4. **中间箭头**：8 段独立虚线 + 箭头头部，黑色 ✓
5. **虚线循环移动**：DashPath offset 动画，0→50px，30帧（60fps），循环播放 ✓
6. **9 个状态**：State0-State8，对应 0-8 位激活码 ✓
7. **状态机控制**：
   - MovementLayer：始终播放虚线移动动画
   - ThicknessLayer：根据 `activationCount` 切换状态，每个状态对应不同数量的加粗虚线段
8. **View Model**：`ActivationViewModel` 包含 `activationCount` 属性（0-8）✓

### 设计细节

#### 虚线分段策略
- 8 个独立 Shape，每个包含独立的 Stroke 和 DashPath
- 段1-7：50px 路径（40px dash + 10px gap）
- 段8：30px 路径（适配到箭头头部）
- 所有 DashPath 同步移动 offset

#### 粗细控制
- 正常粗细：3px
- 加粗粗细：7.5px（3 × 2.5）
- State0：所有段正常粗细
- State1：段1 加粗
- State2：段1-2 加粗
- ...
- State8：段1-8 全部加粗

#### 状态转换逻辑
- 双向转换：支持前进和后退
- 无过渡时间（duration=0），即时切换
- 条件：基于 `activationCount` 的精确匹配和小于比较

### 待参数化（需 RN 集成时实现）

根据原始需求 A-8、A-10、A-12，以下参数暂时硬编码：

1. **箭头颜色**：目前 `FF000000`（黑色），需绑定到 view model
2. **虚线速度**：目前 30 帧循环 50px，约 100px/s（60fps），需通过 AnimationState.speed 控制
3. **粗细倍数**：目前 2.5 倍，需动态计算

### RN 集成要点

1. 通过 Rive runtime 设置 `activationCount`（0-8）
2. 状态机自动根据数值切换对应状态
3. 虚线循环移动始终运行，不受状态切换影响
