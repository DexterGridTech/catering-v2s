# 盘点只留计数与样本,不留成员清单

- **失败模式**:盘点/统计类产物保存了总数、比例和几个抽样,**没有保存那一组成员本身**。
- **根因**:**计数是结论,清单才是产物。** 下游要用的是清单。
  写的人手上有集合,所以感觉不到它没落盘;下一个人手上只有数字。
- **判据**:**下游能不能只拿这份产物就继续工作?** 不能 ⇒ 它没完成。
- **最小解**:凡产出「N 个 X」,同一份产物里必须有那 N 项的清单。

```text
❌  盘点写:「501 个字段值 / 4998 处;前端交集 409;生成物覆盖 383;未覆盖 26。」
    附 10 个随机样本与变异证明。
    → 下一批要对那 26 项逐条判定时,名单不在,只能重扫。
      而重扫得到的集合与当时那个是否同一个,已经无法证明。

✅  同一份产物里附上那 26 项:字段名 · 构造位置 · 形态。
    抽样是抽样,不能代替全集。
```

## 更要紧的推论:没有清单的计数**不可证伪**

别人拿到「26」只能选择相信或不相信 —— **他没有任何办法验证它**。
这正好违反「每条判据必须自带反例」:说不出「出现什么就说明这个数是错的」。

有清单则相反:随便挑一项打开看,对不上就推翻了。

⚠️ **同一个毛病我自己也犯过**:详设里写「304 个跨界字段名零编译器保护」,
同样是一个没有名单的数字。它后来被证明是错的(单文件分母),
而在那之前**没有人能证伪它**,因为没东西可查。

- **判别式**:我写下的这个数,别人怎么才能证明它是错的?
  答不上来 ⇒ 我给的是一个信念,不是一份产物。
