# cs-managed-runtime-execution

R1 is closed and current R2 has no dynamic-execution authority; DEV and runtime remain forbidden. In an explicitly authorized future step, use only the matching managed `scripts/` runner, preserve its session-owned manifest and structured logs, report progress every 30 seconds, and separate business PASS from cleanup PASS. Never kill by port, seed on start/restart, or infer cleanup from process exit.
