- 日期:2026-08-17 · 作者:Claude
- **本文是评审流水,不是实施输入。** 要做什么见
  `doc/plans/platform/2026-08-17-v2s-agent-enablement-implementation-input-claude.md`。
- 它的用途只有一个:**让 Dexter 判断这份材料的可信度**。

## 为什么单独存在

第三轮盲审的核心指控是:方案文档四成篇幅是自我更正,
「一个合格的实施 agent 按该文档自己的停机纪律,读完应该停下来问至少 6 次」。
更正史对实施者只有负价值,对判断可信度有正价值 ⇒ 拆开。

## 三轮盲审

| 轮 | 攻击面 | 结论 |
|---|---|---|
| 一 | 原创方案 | 多条证据不足;指出我把未亲验的转述当依据 |
| 二 | 修订稿 | **NO-GO**,7 条阻断。核心:只改被点名的,没扫同类 |
| 三 | 二次修订稿 | **NO-GO**,M=3/S=9/N=7。核心:**更正叠更正后不可用作实施输入** |

三轮的攻击面各不相同 —— 第三轮那条是前两轮都没碰过的,也是最致命的。

## 我在这条线上的错误(全部由盲审或实施方抓出,无一是我第一遍写对的)

| 错 | 实际 | 性质 |
|---|---|---|
| 「304 个跨界字段名零保护」 | 26,且这 26 也不可信 | 拿**单文件**(294)当整个生成面 |
| 「10 道红门」 | 13 | 排除 4 道后报了个像全集的数 |
| 「15 道已接线」 | static + runtime **两档**,`--validate-only` 只跑 static | 两档混成一个数 |
| 「`runtimeCommands` 43 条」 | 28(43 是两档之和) | **在宣布「必须指明档位」的同一句里又混了一次** |
| 「57 个 `V2S_` 键 / 42 未登记」 | 门的扫描集内 46;`apps` 被**扩展名**挡掉,不是目录 | 拿门管不着的范围算,且因果错 |
| 「`capability-invariants` 红因是冻结快照」 | `javaImports()` 不解析 `import static` | 机制错 ⇒ 药方无效 |
| 「三个回执服务无并发保护」 | 三者都内联调 `pg_advisory_xact_lock` | grep **辅助类名**,漏掉内联实现形态 |
| 「契约里没声明完整 response 形状」 | 948 个对象 schema 中 854 个已封闭,仅 13 个未设 | 继承的判断,未亲验 |
| 「0 条确认的真缺陷」 | `rp12-final-state` 是真缺陷 | 「未确认」≠「确认不存在」 |
| 「评审 545 份」 | 547(且仍在增长) | 该写取值命令而非数值 |
| CP-INV-7 分母「455 / 4496」 | 两次不同过滤下的数字配成一对 | 自相矛盾 |
| CP-19 验收判据「红项与盘点一一对应」 | 混淆两条不同不变量 | 判据本身失格 |

**实施方停机 4 次,4 次都证明上游(我)是错的。** 每次他都没有卡住 —— 是指令本身错了。

## 我采纳的、来自盲审的更好设计

- **接线**:撤回我的 `UNWIRED_BY_DECISION` 台账,改用「让 verify 清单成为唯一清单」
  (但该方案在两档结构下不成立,已在实施输入里改为「逐门指明档位」)
- **`scripts/why`**:不建。改为**把最小修法写进 `fail()` 调用点本身** —— 单一真相,不可能漂移
- **`capability-invariants`**:不改门的解析器,改那**唯一一个**用通配静态导入的生产文件 4 行
- **文档结构**:拆成实施输入 + 本台账

## 我撤回的自己的提议

`scripts/why` · `scripts/applies` · `scripts/precheck` · `scripts/check/all` ·
三道接缝对账门 · 放开 `PreToolUse` · `UNWIRED_BY_DECISION` 台账 · 引入 Spectral ·
引入数据流分析工具。

**净增:0 个 hook · 0 个脚本 · 0 道门。** 唯一新增是详设里一个 `RECALL` 字段。

⇒ 这条线上我提议要建的东西,**最后一个都没建**。每一次「不建」的理由都是同一条:
**先查仓内,或先量一下问题有多大** —— 量完发现要么已有、要么问题比想的小一个数量级。
