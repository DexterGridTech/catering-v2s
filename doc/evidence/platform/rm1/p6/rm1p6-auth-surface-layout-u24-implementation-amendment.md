# RM1P6 authentication surface layout U24 amendment

Dexter requested two visual corrections for both independent admin applications: login forms must be centered, and password-recovery surfaces must use centered cards. The verification-code send control belongs beside the verification-code input.

The finite denominator is the two login screens and the three recovery stages in each app. The existing owner commands, generated clients, session lifecycle, debug OTP behavior, form validation and routes remain unchanged. The smallest remedy is shared naming and local app stylesheet rules for the existing Ant Design Pro login form, plus use of `Space.Compact` for the platform recovery OTP pair, matching the existing login pattern.

No product or authorization behavior is added.
