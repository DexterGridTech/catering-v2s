## 1. 目的、口径与完备性

本附录落实需求正本 [2026-09-16-v2s-store-operating-rule-switches-requirements-claude.md](2026-09-16-v2s-store-operating-rule-switches-requirements-claude.md) §6 R-9.2a 至 R-9.2c。它不是手工挑出的接口样本，而是上列 source hash 下 registry 的**全部 270 条** operation 的逐条分类。

分类规则是固定且可复算的：

1. `STORE（目标解析后才成立）` = `face=operations-admin` 且 owner 属于 `catalog`、`fulfillment-production`、`inventory`、`asset` 或 `sales-menu`。该标记表示 operation 可接收/解析门店目标；同一 operation 命中非 STORE 目标时，gate 必须显式返回，不能误拒绝品牌、项目或其他 owner 事实。
2. `MUTATION` = registry 的 `mode=COMMAND`，且不在三个命名 preflight 中；这类操作在目标为 STORE 时必须调用唯一 gate。命令 adapter 在调用其 owner command **前**执行 gate，故拒绝不会改业务数据。
3. `PREFLIGHT` = `preflightOperationsLocalCatalogCopy`、`preflightOperationsTemporaryCatalogItemPromotion`、`preflightOperationsBrandCatalogCopy`；它们不改业务数据，按 R-9.3 不 gate。
4. `READ` = registry 的 `mode=READ`；按 R-9.3 一律不 gate。
5. 其余行是 `非 STORE`；不得仅因它也是 command 就接入本期开关。

复算结果：STORE 目标可能 operation **89** 条（READ 34、PREFLIGHT 3、MUTATION 52），非 STORE **181** 条；总数 `89 + 181 = 270`。因此真正要求 gate 的分母仍是**52 条**，不是三个 UI 页面，也不是任意抽样的 command。

`operationId`、`adapter` 和 `normalizedPath` 均来自 registry 原字节；实施时若 registry 变更，必须重新生成本附录、重新核对四个计数，并在详设 §8 的 P9 对账中记录差异。不得只手改一行表格。

## 2. 唯一 gate 与调用边界

实施只能新增一个组织 owner 公共读 API `StoreOperatingRuleGate.requireCatalogManagementForStoreTarget(...)`（最终 API 名以详设 §8 为准）。每个下表标为 MUTATION + STORE 的 adapter，须在已有 scope/grant/target 解析已得到真实目标后、第一次 owner mutation 前调用；它根据门店当前 `catalogManagementEnabled` 的 effective 值决定继续或抛出 `ORGANIZATION_STORE_CATALOG_MANAGEMENT_DISABLED`。读取 store 规则或 store 行失败时 fail-closed。gate 不写入，不替代原 capability、scope、生命周期、幂等、锁或 owner readback。

## 4. 防漂移检查

- 登记表新增、删除或改 owner/mode/path/adapter 后，映射必须以当前 registry 重建；旧 source hash 不能证明新 operation 已覆盖。
- 新增的 STORE mutation 若未成为上述 52 条之一，必须同时修改 registry、映射、详设 §8、活动 edge catalog 的 operation augmentation、materialized OpenAPI `x-error-codes`、gate 落点和 acceptance；少任一项均为 `OPEN`。
- 新增非 STORE mutation 不得为了“统一”接入此 gate；R-9.2 的对象是会改变**该门店**商品、库存、销售菜单数据的写入口。
- 本文只证明静态分母与计划落点，尚未证明运行行为；backend acceptance、受管 runtime 与 browser L2 均为 `NOT_EXECUTED / NOT_AUTHORIZED`。
